■ 2. 2つのアイデアを統合したコアコンセプト
--------------------------------------------------------------------
【コンセプト：「声をかけるタイミングがわかるドア」×「ビデオ会議の団らん化」】

1) なぜ普通の電話やZoom、見守りカメラではダメなのか？（社会課題）
   - 電話：「今忙しいかな？」「特別な用事がないのにかけるのは気が引ける」と躊躇してしまう。
   - 見守りカメラ：親のプライバシーを侵害し、「監視されている」という嫌悪感を生む。
   - Zoom / Google Meet：URL発行やスケジュール調整など「業務的」で、昔のSkypeや実家の茶の間のような「ふらっと顔を出して団らんする」温かみがない。
   - 音声のみ：声だけでは顔色やちょっとした体調の変化、部屋の雰囲気がわからず、「本当に元気かな？」というモヤモヤ（気になる気持ち）が払拭できない。

2) 解決策：ドア型・家族団らんアプリ（仮称：となりドア / 団らんドア）
   - アプリを開くと、温かみのある「複数のドア」（例：「実家の茶の間」「おばあちゃんの縁側」「みんなの趣味部屋」など）が並んでいる。
   - 【ドアの外（入室前）：声をかけるタイミングがわかる】
     - 親側の端末（タブレット等）から、Gemini マルチモーダルが定期的に「気配」だけを抽出。
     - 生の監視映像を送るのではなく、「リビングでゆっくりお茶を飲んでいます（声かけおすすめ度：◎）」「テレビを見て笑っています」「お休み中（そっとしておこう）」のように、ドアの明かりと一言タグで『今声をかけていいタイミングか』がわかる！
   - 【ドアの中（入室後）：あえてビデオ通話を強制する「団らん空間」】
     - ドアをノックして開けると、すぐにビデオ通話（WebRTC）がオンになり、顔と顔を合わせた「団らん」が始まる。
     - あえてビデオ通話を必須（カメラON）にすることで、親の顔色・表情・元気さを自然に目で見て確認でき、子や孫の「気になる」を払拭する。
     - 業務的な会議画面ではなく、暖かい部屋のフレーム、Geminiによる「今日のおすすめ話題（季節の話題や最近の出来事）」、一緒に見られる思い出ボードなどで「団らん」を演出する。
   - 【退室後：安心見守りログ】
     - 通話が終わると、Gemini が今日の団らんの様子から「元気度・安心メモ」を自動生成し、家族間で共有できる。

■ 4. 技術スタック案（Google Cloud & Google AI フル活用）
--------------------------------------------------------------------
- 実行基盤（必須）：Google Cloud Run（Node.js / Express + WebSocket + フロントエンド配信）
  ※1コンテナにまとめることで Cloud Run へのデプロイが確実・高速になり、WebSocket によるリアルタイム通信と Gemini API 呼び出しを安全にサーバーサイドで処理できる。
- AI中核：Google Gemini API (`@google/genai` SDK, `gemini-2.5-flash`)
  1. カメラフレーム（画像）＋状況からの「気配・声かけタイミング解析」
  2. 団らん中の「会話のきっかけ（話題カード）生成」
  3. 通話後の「見守り安心サマリー生成」
- ビデオ通話：WebRTC（ブラウザ標準 Camera/Mic + WebSocket シグナリング）＋ デモ用シミュレーター（1人でも親側・子側を切り替えて審査員に実演可能なモード）
- データ保存：Firestore（または Cloud Run インメモリ＋永続化アダプタ）

■ 5. UI・仕様決定事項（2026-11-07 追記）
--------------------------------------------------------------------
- ドア越しの気配表示フォーマット：
  「-{アカウント名}-がくつろいでいます。」
  （例：「-おばあちゃん-がくつろいでいます。」「-kaigunn_2020-がくつろいでいます。」）
- 話題カード：
  - 初期データとして100件の団らん話題カード（`public/data/topics.json`）を搭載し、ランダムに引けるようにする。
  - さらに Gemini API (`gemini-2.5-flash`) によって家族の状況や季節に応じた新しい話題カードもリアルタイム生成できるようにする。
- マルチエージェント開発分担：
  - 統括・100件話題カード生成・バグチェック・動作確認：Antigravity
  - 構成の詳細詰め・サーバー実装：Codex CLI (`codex-sol6.1-high`)
  - ドアのUI・団らんルームUI作成：Claude Code CLI (`opus-5.5-mid`)
